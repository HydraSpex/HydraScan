=========
HydraScan
=========

HydraScan is a Python based control software for scaning probe microscopy. It runs
on Python 3.


Installation
============

The preferred way to install is from source with ``python setup.py install``. You will
need to have `setuptools`_ installed::

    git clone https://github.com/HydraSpex/HydraScan
    cd HydraScan
    python setup.py install

.. _setuptools: https://pypi.python.org/pypi/setuptools
